# biblioteca-unne

Sitio web de **BiblioHub**: una biblioteca pública en una sola página (landing) con catálogo,
búsqueda, reservas, eventos, sedes, investigación y equipo.

HTML + CSS + JavaScript puro, sin dependencias ni build.

## Ver el sitio en local

```bash
npx serve .
```

Abre la dirección que indique (por ejemplo `http://localhost:3000`).

## Estructura

- `index.html`: la página completa
- `css/`: estilos por sección
- `js/`: navegación, carrusel, búsqueda, cuenta, formularios y efectos
- `images/`: logo (PNG sin fondo) y fotos del equipo

Las fotos del collage y de las secciones se cargan desde Wikimedia Commons
(los créditos están en la sección "Créditos de fotos y videos" de la página).
